# Frogger Arcade

A Frogger-style arcade game for Android, built in the style of the 1981 Konami/Sega classic.

- 14x14 playfield: 5-lane road with trucks, racecars, cars, dozers and beetles, then the river: logs and diving turtles
- 5 home bays, bonus fly worth 200 points
- 3 lives, extra life at 10,000 points, levels speed everything up
- Persistent high score
- Touch controls: tap to hop forward, swipe to hop left/right/down

Built with plain Android (no AndroidX), single GameView. Shared debug keystore.
